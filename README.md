# Stealth Render Studio

Локальний headless-браузер як сервіс із веб-UI: рендер сторінок, запис і
відтворення дій, антидетект (Chromium + Camoufox) та конфігуратор.

## Запуск

```bash
npm install              # + автопатч camoufox-js (postinstall)
npm run fetch-camoufox   # бінарник Camoufox (~1.3 ГБ, один раз)
npm start                # http://localhost:3000
```

Потрібні: Google Chrome (для Chromium-режиму) і Postgres (опційно — інакше робота в пам'яті).

## Коротко про можливості
- Рендер URL → fullPage-скриншот + текст, стійко до Cloudflare-заставки.
- Сценарії `Сторінка → Дія → під-дія`: запис рухів/кліків/клавіш/файлів і відтворення.
- Рандом символів, завантаження файлів, людська поведінка при відтворенні.
- Два рушії: **Chromium** (швидко) і **Camoufox** (Firefox-антидетект, проти жорсткого Cloudflare).
- Конфігуратор fingerprint/stealth + лог-консоль життєвого циклу.
- Збереження сценаріїв у Postgres.

Повний опис архітектури та висновки про антидетект — у [CLAUDE.md](./CLAUDE.md).
