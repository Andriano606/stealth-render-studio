# Stealth Render Studio

Headless-браузер як локальний сервіс із веб-інтерфейсом: рендер будь-якої сторінки
через Playwright, запис і відтворення дій користувача, антидетект-режими та
конфігуратор. Побудовано за сесію як дослідницький інструмент, тож код тримає
багато напрацювань про те, як антиботи (зокрема Cloudflare) детектують автоматизацію.

## Швидкий старт

```bash
npm install                 # + postinstall автопатчить camoufox-js
npm run fetch-camoufox      # завантажує бінарник Camoufox (~1.3 ГБ, ОДИН раз)
npm start                   # http://localhost:3000
```

- Потрібен встановлений **Google Chrome** (Chromium-режим використовує `channel: 'chrome'`).
- Потрібен **Postgres** (Postgres.app на macOS). За замовчуванням:
  `postgres://<user>@localhost:5432/playwright_demo`. Перевизначається через `DATABASE_URL`.
  Якщо БД недоступна — апка працює в пам'яті (Дії не зберігаються).

## Архітектура

```
Браузер (UI) ──HTTP──> Express (server.js) ──Playwright──> Chromium | Camoufox
                            │
                            └── Postgres (pages) + файли (uploads/)
```

- **server.js** — увесь бекенд (один файл): пул браузера, рендер, стрімінг відтворення,
  антидетект, Postgres, завантаження файлів, конфіг.
- **public/index.html** — увесь фронтенд (HTML+CSS+JS в одному файлі).
- **scripts/patch-camoufox.mjs** — автопатч бібліотеки camoufox-js (див. нижче).

### Теплий пул браузера
Браузер запускається ОДИН раз і живе весь час. На кожен запит береться готовий
**ізольований контекст** із пулу (`POOL_SIZE = 3`), тож `newContext` ~0 мс. Кожен
контекст використовується рівно раз → ізоляція сесій. Пул поповнюється у фоні.

### Два рушії (перемикач у конфігураторі)
| Рушій | Коли | Швидкість |
|---|---|---|
| **Chromium** (дефолт) | звичайні сайти, скриншоти, масовість | швидко, теплий пул |
| **Camoufox** (Firefox-антидетект) | жорсткий Cloudflare / DataDome | повільніше, але **проходить** |

Camoufox драйвиться тим самим Playwright (через протокол Juggler, а не CDP). У цьому
режимі наші Chromium-патчі НЕ застосовуються — Camoufox має власний антидетект на
рівні C++ рушія.

## Можливості (UI)

- **Рендер URL** → fullPage-скриншот + метадані + витягнутий текст. Навігація
  стійка до Cloudflare (`gotoSmart`: domcontentloaded + очікування зникнення
  «Just a moment…», мовно-незалежно по DOM-маркерах).
- **Таби скрінів** — історія рендерів/відтворень, перемикання між ними.
- **Три рівні сценаріїв:** `Сторінка → Дія → під-дія`
  - **Сторінка** — стартовий URL + список Дій. Кнопка **▶ Старт** відкриває URL і
    послідовно відтворює всі Дії (накопичувальний ланцюг). Працює навіть без Дій
    (просто відкриває URL).
  - **Дія** — один запис (від старту до стопу запису). Згортається, перейменовується,
    видаляється. ▶ на Дії виконує ланцюг до неї включно.
  - **під-дія** — рух миші / клік / текст / клавіша / файл. Редагується й видаляється.
- **Запис** рухів/кліків/клавіш на скриншоті (координати мапляться в CSS-пікселі
  сторінки) → відтворюється через Playwright (`mouse`, `keyboard`).
- **Рандом для тексту** — на текстовій під-дії перемикач 🔒 → 🎲цифра → 🎲літера:
  при виконанні підставляється випадковий символ.
- **Завантаження файлів** — під-дія `file`: файл вантажиться на сервер, при
  відтворенні підставляється напряму в `input[type=file]` (по всіх фреймах, у т.ч.
  iframe) через `setInputFiles` — надійніше за `filechooser`.
- **Лог-консоль** — показує життєвий цикл: рушій, браузер (reuse/launch), контекст,
  що підставлено (fingerprint/cookies/stealth), CF-статус, кроки відтворення (стрім).
- **Конфігуратор** (⚙) — редагує все, що відрізняється від дефолтного Playwright:
  рушій, headless, ізоляція сайтів, stealth-plugin, persistent, людська поведінка,
  fingerprint (UA/locale/tz/platform/cores/screen…).
- **Людська поведінка** при відтворенні: криві рухи миші, змінні затримки, друк по
  буквах, випадкові скроли-«роздивляння».
- Усе зберігається в **Postgres** (таблиця `pages`, Дії як JSONB).

## Антидетект: що працює і ЧОМУ (головні висновки сесії)

Цей розділ — суть того, що з'ясовано експериментально про детектування автоматизації.

### Рівні сигналів (від простих до непереборних у headless)
1. **Задекларовані** (UA, мова, таймзона, екран) — легко підставити (fingerprint).
2. **Наш stealth** (`stealthScript`): `navigator.webdriver=false` НА ПРОТОТИПІ (не
   own-property!), повний `window.chrome`, `outerWidth/Height`, видалення
   `window.__pwInitScripts`, узгоджений `permissions.query`.
3. **stealth-plugin** (puppeteer-extra): плагіни, WebGL та десятки патчів.
   `webgl.vendor`-евейжн ВИМКНЕНО — бо вмикаємо реальний GPU (див. нижче).
4. **Поведінка** — рухи/затримки/друк по буквах/скроли.
5. **CDP-керування** — Chromium керується через CDP, і це детектується (витік
   `Runtime.enable`). Приховати init-скриптом НЕ можна (це канал керування, а не
   сторінка). Патчиться лише на рівні драйвера (`rebrowser-patches`/`patchright`).
6. **«Живий» рендер** — Canvas/WebGL реальним GPU. Увімкнено апаратний GPU на Mac:
   `--use-gl=angle --use-angle=metal` → реальний Apple-рендер замість софтверного
   SwiftShader. Назву WebGL НЕ спуфимо (щоб не суперечити реальним пікселям).
7. **Репутація IP** — резидентний проходить, дата-центр (VPN/Hetzner) блокується ЖОРСТКІШЕ.

### Ключові відкриття про Cloudflare
- **`window.__pwInitScripts`** — Playwright створює цей об'єкт на сторінці через
  `addInitScript`. Це прямий підпис Playwright. Прибирається видаленням об'єкта в
  кінці init-скрипта (ми це робимо).
- **`navigator.webdriver`** має бути `false` (а не `undefined` і не own-property).
  Наш спуф на прототипі — щоб `Object.getOwnPropertyNames(navigator)` був чистий.
- Перевірка стелсу: **https://bot-detector.rebrowser.net** — ми довели 3/3 зелені
  (runtimeEnableLeak, navigatorWebdriver, pwInitScripts) для Chromium + реальний GPU.
- **АЛЕ Cloudflare на деяких сайтах (rubyonremote) блокує навіть при 3/3 зелених і
  реальному GPU — і навіть у headful.** Висновок: він детектує сам факт керування
  фреймворком (Chromium/CDP) + середовище, а не лише JS-сигнали. Chromium тут
  непрохідний жодними нашими засобами.
- **Переможне рішення — зміна рушія на Camoufox (Firefox).** Firefox керується
  протоколом Juggler, а НЕ CDP → увесь клас CDP-детекції Cloudflare не застосовний.
  Fingerprint вшитий у C++ рушія, тож JS-слідів немає. Camoufox ПРОХОДИТЬ rubyonremote.

### Що таке Camoufox (важливо не плутати)
- **Playwright** = драйвер (керує браузером). Багатодвигунний: Chromium→CDP,
  Firefox→Juggler, WebKit→свій протокол. Один API — різні «перекладачі» всередині.
- **Camoufox** = браузер (кастомна збірка **Firefox**), аналог Chromium, НЕ Playwright.
  Будується поверх Firefox-збірки Playwright (з Juggler) + антидетект-патчі в C++.
  `camoufox-js` каже Playwright: `firefox.launch({ executablePath: <camoufox> })`.

## База даних

- `pages(id BIGINT PK, name, url, recs JSONB, created_at, updated_at)` — Сторінки з
  вкладеними Діями (recs) та під-діями (subs у JSONB).
- `recordings(...)` — legacy-таблиця (стара пласка модель Дій), лишена для сумісності.
- Таблиці створюються автоматично при старті (`initDb`).

## Патчі сторонніх бібліотек

- **camoufox-js 0.10.2** має баг: генератор fingerprint видає навігатор-властивості,
  яких немає в `properties.json`, і валідатор падає. `scripts/patch-camoufox.mjs`
  робить валідатор поблажливим (пропускає невідомі властивості). Запускається
  автоматично через `postinstall`, тож переживає `npm install`.

## Відкинуті підходи (і чому)
- **rebrowser-patches / patchright** (приховування CDP) — закривали CDP-витік
  (детектор зеленів), АЛЕ rubyonremote все одно блокував, і вони вимагають
  playwright-core 1.52, що конфліктує з Camoufox (1.63). Прибрано на користь
  Camoufox, який і є реальним рішенням для жорсткого Cloudflare.
- **VPN/дата-центр IP** — для Cloudflare гірше за домашній резидентний IP.
